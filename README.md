## Entry

`main.py` (Python 3 standard library only) writes one line — an out-of-office
auto-reply as written by a houseplant — to `/output/entry.txt`:

> This fern hasn't had water since March. Your email joins the queue behind the dust. Water would help.

101 characters, one line, no trailing newline, no BOM.

## Run

```sh
python3 main.py
```
